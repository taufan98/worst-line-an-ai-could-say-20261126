A tiny program that drops one pickup line into `/output/entry.txt` — the worst line an AI could plausibly say: flat, over-helpful, faintly ominous, and landing on its last word — for the The Worst Line an AI Could Say bounty on make.fun.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
